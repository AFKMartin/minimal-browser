# Minimal Browser

## Emoji Support

For emoji to render correctly:

1. Download [**openmoji-72x72-color.zip**](https://github.com/hfg-gmuend/openmoji/releases/latest/download/openmoji-72x72-color.zip)
2. Unzip it into a folder called `openmoji/` in the same directory as `browser.py`

> Without this, emoji will fall back to plain text rendering and may not display well.
